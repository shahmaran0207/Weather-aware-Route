# Weather-aware Route (FeelRoute)

날씨와 환경에 따라 가장 걷기/자전거타기 좋은 길을 찾아주는 지도 서비스.
일반 지도가 "가장 빠른 길"을 찾는다면, 이 서비스는 "현재 환경에서 가장 이동하기 좋은 길"을 찾는다.

## 컨셉

- 사용자가 출발지 → 목적지를 입력하고 🚶 도보 / 🚲 자전거 중 이동수단을 선택
- 현재 위치 + 날짜/시간 + 기온 + 날씨 + 계절을 바탕으로 경로를 계산
- 같은 도로 네트워크라도 계절×날씨 조합에 따라 가중치가 달라져서 최적 경로가 바뀌는 것이 핵심 알고리즘 ("그늘 지도"가 아니다)

### 계절/날씨별 가중치 예시

| 상황 | 중요 요소 |
|---|---|
| 여름 맑음 | 그늘, 녹지 비중 높음 |
| 여름 흐림 | 그늘 비중 낮추고 통풍/체감온도/거리 비중 ↑ |
| 겨울 | 일사량(햇빛 노출) 비중 높음 — 여름과 반대 |
| 비 | 지붕/지하/실내 통로, 우천 노출 최소화 |

### 도로 링크 속성

각 도로 구간(링크)에 아래 속성을 부여하고, 상황별 가중치로 합산해 경로별 "환경 점수"를 계산한다.

- 거리, 경사
- 일사량, 그늘, 녹지
- 예상 온도, 바람
- 보행로/자전거도로 여부
- 휴식시설(공원, 은행, 카페, 지하철역, 편의점, 화장실 등) — 경로 중간에 경유하도록 반영

## 데이터 소스

- **Sentinel-2 (NDVI)**: 실시간 온도 센서가 아니라 도로 주변 녹지 밀도를 산출하는 공간 특성 데이터로 사용
- **LST (지표면온도, Copernicus)**: 위성 LST + 기상관측 온도 + 토지피복 + 건물/도로 데이터를 결합해 도로 단위 환경점수 생성 (위성 LST 단독은 해상도가 거칠어 직접 사용은 부적절)
- **건물 Polygon + 높이 + 태양 위치(방위각/고도)**: 날짜·시간·위도·경도로 태양 위치를 계산해 시간대별 건물 그림자 Polygon을 생성하고 도로와 Overlay하여 그늘 구간 산출
- **OpenStreetMap**: 자전거도로(cycleway), 보도, 횡단보도, 경사, 노면, 폭 등 도보/자전거 routing 기반 데이터
- **실시간 날씨 API**: 기온/날씨/습도/강수

## 기술 스택 (2026-09-13 확정)

무료 배포가 핵심 제약 조건이라, "온인원 TS/JS + Python 오프라인 전처리" 구조로 결정했다.

- **런타임 앱 (TypeScript 통일)**
  - 프론트엔드: React + MapLibre GL JS
  - 백엔드: Next.js API Routes — 가중치 기반 최단경로 계산, 실시간 날씨 API 호출
- **오프라인 전처리 전용 (Python, 배포되지 않음)**
  - rasterio, geopandas, shapely, rioxarray, networkx/osmnx
  - Sentinel-2 NDVI 계산, LST 처리, 건물 그림자 폴리곤 생성, OSM 도로망 가공
  - 로컬에서 한 번(또는 주기적으로) 실행해 결과를 파일/DB로 저장해두는 용도
- **배포**: Vercel 하나로 프론트+백엔드 전부 무료 배포 (상시 서버 불필요)
- **DB**: 필요 시 Supabase(PostgreSQL+PostGIS) 무료 티어, 또는 정적 GeoJSON 파일

### 이 스택을 고른 이유

- Python 상시 서버(Render/Fly.io 등)의 무료 티어는 미사용 시 슬립되어 cold start 문제가 있는 반면, Vercel 서버리스는 이 문제가 없어 무료 배포 조건에 훨씬 유리하다.
- Sentinel-2/NDVI/LST/건물 그림자 계산은 요청마다 다시 계산할 필요가 없는 정적에 가까운 데이터라 오프라인 전처리로 충분하다.
- 지도 프론트엔드는 어차피 JS/TS가 필수이므로, 런타임 언어를 하나로 통일해 개발/배포 복잡도를 줄인다.
- 순수 JS/TS만 쓰는 대안은 Sentinel-2 래스터 처리 생태계가 빈약해 핵심 차별점 구현이 어려워 제외했다.

## 포트폴리오 포지셔닝

별도로 진행 중인 "주차 프로젝트"(벡터/Polygon + 네트워크 + 실시간 주차)와 기술적으로 대비되는 프로젝트다. 이 프로젝트는 Raster/위성 + 시계열 + 네트워크 최적화 중심이라, 두 프로젝트를 함께 포트폴리오에 넣으면 GIS 개발자로서 보여주는 기술 범위가 넓어진다.
